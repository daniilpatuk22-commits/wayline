# Wayline — сайт проекта

Статический сайт для открытого оверлея Path of Exile 1 и 2. Без сборки и зависимостей: HTML, CSS и немного JavaScript.

## Файлы

- `index.html` — разметка и тексты
- `styles.css` — оформление и адаптивная вёрстка
- `main.js` — мобильное меню, ссылка на последний релиз, копирование, демо окна
- `favicon.svg` — значок

## Перед публикацией

1. Замените `your-username/wayline` на свой репозиторий в `index.html` и `main.js`.
2. Добавьте в репозиторий файл `LICENSE` с текстом MIT: на него ведёт ссылка в подвале.
3. Сверьте тексты, горячие клавиши и описание функций с реальным приложением.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите файлы в ветку `main`.
2. Откройте Settings → Pages → Build and deployment.
3. В поле Source выберите Deploy from a branch, ветку `main`, папку `/ (root)`, сохраните.
4. Сайт появится по адресу `https://<ваш-логин>.github.io/wayline/`.

## Публикация на Cloudflare Pages

Подключите репозиторий, оставьте команду сборки пустой, а папку вывода укажите `/`.

## Как работает скачивание

`main.js` запрашивает последний релиз через публичный API GitHub и ставит кнопкам прямую ссылку на файл `.exe` или `.msi`. Если релизов ещё нет, сайт покажет «Первый релиз скоро появится» и оставит ссылку на страницу релизов.
